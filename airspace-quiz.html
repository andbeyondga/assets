The "Wedding Cake" — Side View

Most controlled airspace is layered. Memorize this picture — it's the foundation of every airspace question.

Class A (no drones)
Class B / D (blue)
Class C / E (magenta)
Class G (uncontrolled)

A Class A

18,000 MSL → FL600. IFR only. Drones cannot fly here — irrelevant for Part 107 ops, but you must know the ceiling.

B Class B

Surface → 10,000 MSL around the busiest airports (KATL, KLAX, KJFK…). Upside-down wedding cake.

Sectional: Solid blue lines.
Part 107: Authorization required (LAANC).

C Class C

Surface → 4,000 AGL around busy airports with a control tower + radar approach. 2 rings: 5 NM inner, 10 NM shelf.

Sectional: Solid magenta lines.
Part 107: Authorization required (LAANC).

D Class D

Surface → 2,500 AGL (typically) around towered airports. Single cylinder, ~4 NM radius.

Sectional: Dashed blue lines.
Part 107: Authorization required (LAANC).

E Class E

The "default" controlled airspace. Floor depends on chart depiction:

  • Dashed magenta: E to surface (at non-towered airports w/ instrument approach) — auth required.
  • Magenta vignette (fuzzy magenta): E starts at 700 AGL. Below = Class G.
  • Blue vignette (fuzzy blue): E starts at 1,200 AGL. Below = Class G.
  • Otherwise E starts at 14,500 MSL.

G Class G

Uncontrolled. Everything below Class E that isn't B/C/D. No ATC authorization needed.

Drones flying ≤400 AGL in rural areas with no airport nearby are almost always in Class G.

How each class looks on a Sectional Chart

These are the visual cues you'll need for the exam. Click between Learn and Symbols, then go to the Quiz.

Class B — Solid Blue

Two thick solid blue rings. Numbers like 100/SFC mean ceiling 10,000 MSL, floor surface.

Class C — Solid Magenta

Two thick solid magenta rings. 42/SFC → ceiling 4,200 MSL.

Class D — Dashed Blue

Single dashed blue circle. Bracketed number [25] = ceiling in hundreds of feet MSL.

Class E to Surface — Dashed Magenta

Dashed magenta ring around a non-towered airport with an instrument approach. Auth required for Part 107.

Class E 700 AGL — Magenta Vignette

Soft, fuzzy magenta shading. E begins at 700 AGL; below is Class G — fly freely under 400'.

Class E 1,200 AGL — Blue Vignette

Soft, fuzzy blue shading. E begins at 1,200 AGL; below is Class G.
